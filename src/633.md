I finally decided to write a proper Markdown explanation. Somehow Project Euler currently considers this the hardest problem I've solved, although I don't think it is. But I admit in my previous Mathematica solution I didn't understand `SymmetricPolynomial`.

The formula for $c_7^\infty$ was inspired by the well-known derivation for $c_0^\infty$, 
the (limit) proportion of square-free integers. 
It comes from
$$\left( \frac{3}{4} \right) \left( \frac{8}{9} \right) \left( \frac{24}{25} \right) \cdots$$

using the reasoning of in the limit, $3/4$ aren't div by $2^2$, 
$8/9$ aren't div by $3^2$, etc. and each $p^2$ is independent due to CRT.

This is 
$$\prod_p \left( 1 - \frac{1}{p^2} \right) = \zeta(2)^{-1} = \frac{6}{\pi^2}$$
from the **Euler product**.

For $k = 1$, we can consider disjointly, for each $p$, multiplying $6 / \pi^2$
by $1 / (p^2 - 1)$, to include div by $p^2$ instead of exlcuding it.
For example, for $p = 2$, $(3 / 4) (1 / 3) = (1 / 4)$.

I verified 
$$
c_1^\infty = \frac{6}{\pi^2} \sum_p \frac{1}{p^2 - 1}
$$

For larger $k$, we want to scale by the sum of the product of all $k$-subsets of primes
$$
\sum_{i_1 < \cdots < i_k} \left( \frac{1} {p_{i_1}^2 - 1} \right) \cdots \left( \frac{1} {p_{i_k}^2 - 1} \right)
$$

I long time ago I asked on Math Stack Exchange and learned this can be computed exactly with **Newton's identities**.

Define the elementary symmetric polynomials:
$$ e_k(x_1, \dots, x_n) = \sum_{i_1 < \cdots < i_k} x_{i_1} \cdots x_{i_k}$$

i.e. sum of product of all $k$-subsets of $\{x_1, \dots, x_n\}$. 

Define $k$-power sums:
$$ p_k(x_1, ..., x_n) = \sum{x_i^k} $$

Newton's identities gives us a convenient way of computing $e_k$:

$$e_k = \frac{1}{k} \sum_{i=1}^k (-1)^{i-1} e_{k-i} p_i$$

So I can compute from power sums with $n$ terms instead of over $n \choose k$ k-tuples.

Another way to do it is to generate all 7-subsets until the denominator of the factor gets very small. Or use a fancy generating function approach using the complete exponential Bell polynomials.
